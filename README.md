# TRUE DREAM HOMES - Mobile Appointment Booking App UI/UX

This project was created as part of the Future Interns UI/UX Design Internship Program.

## Project Overview

TRUE DREAM HOMES is a modern mobile application designed to simplify home design consultation booking. The app connects customers with experienced architects and civil engineers, allowing them to book appointments, discuss their ideas, and receive customized 2D floor plans and realistic 3D home designs.

Our mission is to transform every customer's vision into reality through innovative design and professional consultation.

## Features

- User Registration & Login
- Home Design Service Selection
- Expert Architect Consultation
- Appointment Date & Time Booking
- Appointment Confirmation
- Simple & User-Friendly Navigation

## Screens Included

- Splash Screen
- Login Screen
- Home Dashboard
- Service Selection
- Expert Consultation
- Appointment Booking
- Confirmation Screen

## Tools Used

- Figma
- GitHub

## Design Style

- Modern UI
- Premium Architecture Theme
- Minimal Design
- Mobile First Design
- User-Friendly Experience

## Project Goal

To provide an easy and efficient platform where customers can connect with professional architects and civil engineers, share their home design ideas, and book consultations for personalized architectural solutions.
